========================================================
  COPILOTE ENTRETIEN IA — Extension Chrome (100% GRATUITE)
========================================================

Cette extension fonctionne SANS SERVEUR : tout tourne dans votre
navigateur. L'IA est appelée directement chez Google Gemini avec VOTRE
propre clé gratuite. L'historique est stocké localement sur votre PC.

------------------------------------------------------------
ÉTAPE 1 — OBTENIR UNE CLÉ GEMINI GRATUITE (2 min)
------------------------------------------------------------
1. Allez sur :  https://aistudio.google.com/app/apikey
2. Connectez-vous avec un compte Google.
3. Cliquez "Create API key" / "Créer une clé API".
4. Copiez la clé (elle commence par "AIza...").
   → C'est gratuit (quota généreux pour un usage personnel).

------------------------------------------------------------
ÉTAPE 2 — INSTALLER L'EXTENSION (Chrome ou Edge)
------------------------------------------------------------
1. Décompressez le .zip → un dossier contenant "manifest.json".
2. Ouvrez  chrome://extensions   (ou  edge://extensions ).
3. Activez le "Mode développeur" (en haut à droite).
4. Cliquez "Charger l'extension non empaquetée" et choisissez le dossier.
5. L'icône "Copilote Entretien IA" apparaît → cliquez dessus.

------------------------------------------------------------
ÉTAPE 3 — COLLER LA CLÉ
------------------------------------------------------------
Au premier lancement, la fenêtre "Réglages IA" s'ouvre.
Collez votre clé Gemini, choisissez le modèle (Gemini 2.5 Flash
recommandé), puis "Enregistrer". C'est prêt !

------------------------------------------------------------
UTILISATION
------------------------------------------------------------
- Mode Candidat : collez/dictez la question du recruteur → 3 puces à dire.
- Mode Recruteur : simulation d'entretien, une question à la fois.
- Micro : autorisez le microphone quand Chrome le demande.
- Image : bouton image pour les tests de logique visuelle.
- Tout reste privé : clé + historique stockés uniquement sur ce PC.
